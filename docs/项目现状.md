# 青山·项目现状（写给作者本人）

> 2026-09-05 ｜ 这份文档用大白话讲清楚：现在什么能用、什么有问题、还欠什么。
> 你不需要懂任何技术词，每一句都是"对你意味着什么"。

## 一、青山是什么（一句话）

一个装在你 iPad 里的 AI 助手 App：你跟它说话，它不光回答，还能**真的动手干活**——它内置了一台隐形的小电脑（Linux 系统），可以在里面装软件、写文件、跑程序。

## 二、现在什么能用（你亲眼验证过的）

| 能力 | 状态 | 说明 |
|---|---|---|
| AI 对话 | ✅ 能用 | 接你自己的 API Key，流式回答，支持多家兼容接口（你自己配的中转站也能用） |
| 动手干活 | ✅ 能用 | 它能在沙箱里真实执行命令——你测过：装 Python、写网页游戏、起服务器，都跑通了 |
| 干活有分寸 | ✅ 能用 | 危险操作前会先弹卡问你（允许一次/始终允许/拒绝）；拒绝了它会换方案 |
| 沙箱有记性 | ✅ 能用 | 它装过的东西、去过的目录，下次还在（不是每次从零开始） |
| 跨对话记忆 | ✅ 能用 | 你告诉它的事，它记下来；杀掉 App 重开，它还记得（你实测"秒答"） |
| 对话不丢 | ✅ 能用 | 所有对话自动存档，杀 App 重开原样恢复 |
| 手动终端 | ✅ 能用 | 右栏有个真终端，你自己也能敲命令 |

**以上每一条都是你在 iPad 上亲手验证过的，不是我说的。**

## 三、能用但有过毛病、刚修过的

| 事项 | 发生了什么 | 现状 |
|---|---|---|
| 命令超时太短 | 你装 Python 时 30 秒就被掐断，装了好几次才成功 | 已放宽（默认 60 秒，下载安装类自动 240 秒，AI 也可以自己指定更久）——**待你复测** |
| 写大文件失败 | AI 写 17KB 的网页文件时被截断 | 已改成不走终端、直接写文件——**待你复测** |
| 被中断太频繁 | 干到 12 步就被强制终止（你两个对话都死在这） | 已放宽到 48 步，24 步时只会提醒不会掐——**待你复测** |
| 记忆排序问题 | 记忆多了以后，新记忆可能被旧的挤掉 | 已修——待积累更多记忆后观察 |

## 四、确实存在的安全问题（正在修）

审计发现了一个**重要漏洞**：AI 执行的命令如果长得复杂（一条里套了好几个动作），审批系统可能认不出来，会**不问你就直接执行**。对你个人的实际风险：你自己的设备、你自己的 API，攻击需要有人诱导 AI——日常自用风险低，但这是个必须堵上的洞（已列入下一批修复，排在第一位）。

另有相关风险：它自动提炼的"记忆"可能被恶意网页内容污染（长期影响后续对话）——防护也在下一批。

## 五、还没做的（不是坏了，是还没轮到）

| 缺的东西 | 对你意味着什么 | 计划 |
|---|---|---|
| 锁屏/切后台后，AI 的活会暂停 | 不能让它"后台跑一晚上任务" | 下一批（底层能力其实已经内置了，就差接根线） |
| 任务队列/定时任务 | 不能让它"每天早上自动干活" | M7 |
| 插件扩展 | 不能加装第三方能力包 | M7 |
| 界面和原型的差距 | 部分细节形态和 HTML 原型不同（如计划列表、逐行代码对比的展示） | 批 3 |
| **自动化测试为零** | 每次改动靠你亲手测——这是你累的根源之一 | M8 重点 |
| 崩溃恢复保障 | 极端情况下（内存告急）可能丢当前任务的进度 | M8 |

## 六、你现在的全部家当（丢不了）

- **代码**：GitHub 仓库（`github.com/Da-AiXZ/QingShan`），每次改动都有存档，6 个版本 tag
- **文档**：项目里的 `docs/` 目录——现状账、对标分析手册 9 份、审计报告 4 份、给 AI 的上手指南（AGENTS.md）
- **已验证的经验**：每个里程碑怎么验收的、踩过的坑怎么修的，全部记录在案

**最坏情况兜底**：哪怕现在什么都不再开发，已完成的 M0-M6 是独立可用的——这个项目没有"全部作废"的风险。

## 七、下一步的三条路（你选，不急）

1. **继续修**——按清单把安全问题和已知毛病修完（预计 2-3 批，每批你验收一次），修完进入"敢天天用"状态
2. **先停一停**——什么都不改，你用现在这版日常体验几天，把真实的别扭攒起来再定优先级（问题清单反正跑不掉）
