## 二、P0 缺陷清单（✅ 全部已于批 1 修复，2026-09-05，run 33932258073）

> 以下 12 项已在批 1 全部修复并通过构建；本节保留作为记录。验证方式：真机复测 + 后续审查复核。

### 安全
- **S1-1 审批免审绕过**：`Approval.swift` needsApproval 的 isSafe 第二个 `contains(where:)` **无 anchored**——`cat x; rm -rf /` 命中 `^cat\b` 免审放行。修：删除无锚点检查，全部走 anchored 整条匹配。
- **S1-2 write_file heredoc 逃逸**：内容含单独一行 `QSEOF` 即截断/注入任意命令。修：改 base64 管道（`echo <b64> | base64 -d > path`）。
- **S1-3 脱敏缺失**：Phase1 transcript 原样上传，密钥可落盘 entries.json。修：上传前+入库前跑确定性 redact（token/password 正则集）。

### 数据完整性
- **D-1 resume 写坏日志**：`load()` 重建 SessionLog 不恢复 seq 游标 → 继续聊重写 header/seq 从 1 重排。修：SessionLog 增加 `resume(seq:)` 或 load 时读末行 seq。
- **D-2 未知工具回喂格式**：只回 llmHistory，落盘 agent/message → resume 后 tool_calls 无结果，DeepSeek 400。修：未知工具也落 tool/call+tool/result。
- **D-3 重命名破坏 append-only**：全量重写 JSONL 且与 append 队列竞态。修：标题存 header 外部（meta 文件），不改日志。
- **D-4 entries.json 损坏静默清库**：load 失败置空 → 下次整合清空全部。修：解析失败时备份原文件并拒载。
- **D-5 compact 重建丢注入**：compact 后历史用裸 systemPrompt，丢 AGENTS.md/记忆摘要。修：compactedHistory 用 initialSystemPrompt。

### 正确性
- **C-1 引用排序比较器错位**：`($0.usageCount, $1.lastUsage??$1.generatedAt) > ($1.usageCount, $0.lastUsage??$0.generatedAt)` tiebreak 反向 → 新记忆被 top-N 截掉。一行修：`($0.usageCount, $0.lastUsage ?? $0.generatedAt)`。
- **C-2 上下文窗口 8k 硬编码**（CtxUsage）：真实窗口 64k-128k → 过早 compact + CtxRing 虚高 8-16 倍。修：常量改 64_000 并可配。
- **C-3 mem.extracted 永久标记**：会话只提取一次，长会话后半段永远丢失。修：记录已提取的事件水位（seq），超水位增量再提取。
- **C-4 右栏空态"浏览器"错开终端**：RootView rightRow("safari"...,"term")。一行修。

### 能力缺口（高优先）
- **G-1 turn 无取消/审批无超时**：失控 turn 只能等 12 步护栏；审批无应答永久挂起（违 fail-closed）。修：LLM 流 Task 取消 + 审批卡 120s 超时默认 deny。
- **G-2 输出无截断上限**：大 cat 全量进 llmHistory。修：16k 字符 + `<clipped>` 提示（dsh 语义）。
- **G-3 governor 未接线**：ISHKernel.m:1581-1830 **已完整实现** CPU governor，Swift 侧零调用。修：boot 后调用 + beginBackgroundTask 保护管线。
- **G-4 shell 退出无自愈**：exit 后每条命令静默吃满 30s。修：检测 shell 死亡 → 重建 + 提示。
- **G-5 项目隔离**（记忆+执行目录重置）——待确认口径后做。

# M6.7 分析收官：批 2 施工清单（2026-09-05，基于 5 份手册）

> 证据源：docs/analysis/01~05（dsh 参数 36 项对照 / iSH 差异 45 条 / iOS 生命周期 36 格 / 失败模式 68 项+8 威胁场景 / 外部情报档案）。团队已解散，手册永久入库。

## 批 2A · 安全（最高优先）
1. **审批解析重修**：白名单仅对"单命令"生效；含 `;`/`&&`/`||`/管道/`$()`/反引号/`-exec`/`-delete`/`env` 借道的复合命令**一律走审批**（`.anchored` 只锚开头，批 1 修复不彻底——实测 `cat x; rm -rf /` 仍免审）
2. **allowAlways 粒度**：从"整个工具"改为"命令首词类别"（run_command 免审 ≠ 任意命令免审）
3. **记忆投毒防护**：Phase1 prompt 加"指令性内容不提取"硬规则 + 新条目首次注入标注未验证 + /memory 路径写入强制审批（Codex 三重防护对齐）
4. **持久 shell 命令黑名单**：exit/logout/reboot 拦截（杀 shell = 永久假死）

## 批 2B · 数据与协议正确性
5. resume 孤儿 tool 消息合成闭合事件（防 DeepSeek 400 永久报废）
6. reasoning_content 持久化进 llmHistory 并按 V4 要求回传（带 tools 不回传 = 400，社区最高频故障）
7. thinking mode 真实接入：`{"thinking":{"type":"enabled"/"disabled"}}` + `reasoning_effort: low/high/max`（滑块联动；注意不发 ≠ 关闭、思考模式下采样参数无效）
8. 上下文窗口按模型可配（V4-Flash = 1M）+ 显式 max_tokens（缺省 4096 会截断长回复）
9. DeepSeekAdapter `timeoutInterval=120`（总时长）改为空闲看门狗语义（dsh streamIdle 300s）——长思考流必被掐死的下一颗雷

## 批 2C · 能力补全
10. governor 接线（LifecycleCoordinator：didEnterBackground/willEnterForeground/后台冷启动三时机幂等；OpenMinis 样板在）
11. shell 自愈（死亡检测 → 重建 + 告知）
12. turn 取消 + 审批 120s 超时默认 deny
13. 输出流解冻后 90s hang 检测
14. 项目隔离（记忆按项目 + 会话切换重置 cwd）
15. 记忆提取水位（增量提取，修"永久只提取一次"）
16. 环境差异规则化：inotify 假实现检测（watch 类任务告知不支持）、ping 不可用告知、ash 无 pipefail 落盘关键管道、NO_COLOR/TERM=dumb/PAGER=cat 注入

## 参数修正批（对照 01 号手册逐条）
max_tokens 256k 随请求发送 / 重试 5 次指数退避上限 10s 带 0.1 抖动（可重试码含 TIMEOUT/TRANSPORT/EMPTY_RESPONSE）/ compaction 尾部保留 retainRatio=0.16 / 超时后持久 shell reset（dsh 语义，替换纯 Ctrl-C）/ 重复工具软提醒照抄（同工具 3/5/8 次注入，替代硬计数）
